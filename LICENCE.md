## 🧩 About

**RF Online overlay** is a curated list of RF Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, overlay notes
- **Quality-of-Life Helpers** — loot tracker, map notes, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- overlay Overlay — visualize nearby entities and distances
- Hitbox Viewer — display hitboxes for study
- Replay Notes — record and review combat encounters
- Playback Speed — adjust overlay refresh for study (0.1x to 5x)

### 🎒 Inventory & Loot
- Loot Tracker — track item drops and locations
- Inventory Notes — organize item categories
- Auto-Loot Helper — streamline pickups for study

### 🗺️ World & Navigation
- Map Overlay — waypoints and points of interest
- Teleport Notes — record coordinates for practice
- Resource Node Tracker — locate mining and gathering nodes

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
